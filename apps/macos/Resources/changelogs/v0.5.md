## What's new in Myna 0.5

### A quieter first launch (0.5.1)
- Myna's background service now appears as **Myna Voice** in macOS's
  "Background Items Added" notice and in Login Items, instead of "python".
- A fresh install no longer opens the system Accessibility prompt on top of
  the installer. The installer asks for it once setup is done.

### One download, no Terminal
Myna now installs from a single disk image. Drag it into Applications, open
it, and it sets up its own voice: a private Python runtime, the speech engine
and the Kokoro voice model, each step shown as it happens. No Homebrew, no
commands to paste. Homebrew installs keep working exactly as before.

If you open Myna straight from the disk image, it offers to move itself into
Applications first. When setup finishes, it asks for Accessibility and, on a
fresh install, goes straight into the spoken introduction.

### An icon of its own
Myna finally has a proper app icon, in Finder, Launchpad and the Dock.

### Fixes
- Tapping an item in Recent reads the whole thing again, not just its first
  sixty characters.
- When Myna's voice isn't running, the menu shows a **Set up Myna…** button
  instead of a dead end.
- **Restart daemon** now works on Homebrew installs, which it silently didn't.
- The introduction points at the real read shortcut, ⌘⌥⇧S.
- The read-article shortcut explains itself when there's no Chrome tab to read.
- This window shows proper headings and lists instead of raw formatting.
- Settings text for gestures, Claude Code replies and buffered playback now
  describes what those settings actually do.
